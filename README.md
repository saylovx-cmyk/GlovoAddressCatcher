# Glovo Address Catcher — test build

Это тестовая Android-программа для проверки, отдаёт ли Glovo Rider адрес/описание точки доставки через Android Accessibility до автопринятия.

## Самый простой способ получить APK через GitHub

1. Создай новый **public или private repository** на GitHub.
2. Загрузи **всё содержимое этого ZIP** в корень репозитория.
3. После загрузки открой вкладку **Actions**.
4. Выбери workflow **Build APK**.
5. Нажми **Run workflow**.
6. Подожди примерно 1–3 минуты.
7. Открой завершённый запуск.
8. Внизу страницы, в разделе **Artifacts**, нажми:
   **GlovoAddressCatcher-debug**
9. Скачается ZIP с файлом:
   `app-debug.apk`
10. Распакуй ZIP на телефоне и установи `app-debug.apk`.

Android может попросить разрешить установку приложений из браузера/файлового менеджера.

## После установки

1. Открой **Glovo Address Catcher**.
2. Нажми **Включить Accessibility**.
3. Найди **Glovo Address Catcher** и включи службу.
4. Вернись в приложение — статус должен стать `Accessibility: ВКЛЮЧЕН ✓`.
5. Во время сессии открой Glovo Rider и дождись заказа с автопринятием.
6. После заказа вернись в Catcher и нажми **Обновить данные**.
7. Нажми **Поделиться логом** и отправь этот текст в ChatGPT.

## Что делает v0.1

- Не нажимает кнопки в Glovo.
- Не принимает/отменяет заказы.
- Не модифицирует Glovo.
- Не имеет разрешения INTERNET.
- Локально сохраняет доступные Android Accessibility-данные.
- Показывает небольшую тестовую плашку поверх Glovo через Accessibility Overlay.

Это диагностическая версия. После первого реального теста можно будет сделать нормальную плашку с адресом доставки.
